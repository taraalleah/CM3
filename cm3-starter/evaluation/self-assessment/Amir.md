# Self-Assessment - Amir

This was a team project with Amir, Olga, Stefan and Tara. I mostly helped on the backend.

What went well:

- I helped build the VehicleRental CRUD controllers and wrote some of the backend tests
  with Vitest and Supertest.
- I worked on the auth controllers for Part B.
- Branches, pull requests and merging `main` in often kept things tidy.

What was harder:

- Getting the tests to run cleanly against MongoDB took a few tries.

  others.

What I would do better:

- Clean up leftover scaffold code before merging.
- Add tests for the auth endpoints too.

I learned a lot about structuring an Express and Mongoose API, testing it with Supertest,
and how JWT and bcrypt auth work. Mostly it was a good team effort and everyone pulled
their weight.
